# Security Policy

## Supported Versions

Currently, the `main` branch of GASC-Governor-Gateway receives security updates.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability in the GASC-Governor-Gateway (including bypasses of the Transit Containment mechanisms, unexpected verifier escapes, or OPA injection vectors), please report it privately.

Contact the maintainers directly at:
**security@odingard.com** (Placeholder for official contact)

We take all security vulnerabilities seriously and will aim to respond within 48 hours to coordinate a fix and coordinated disclosure.
