# Contributing to GASC-Governor-Gateway

Thank you for your interest in contributing to the GASC-Governor-Gateway! We welcome bug reports, feature requests, and pull requests.

If your pull request is substantial, you may be asked to sign a formal Contributor License Agreement (CLA) with Six Sense Enterprise Services LLC before it can be merged. This ensures that Six Sense Enterprise Services LLC retains the rights to commercially license the code in the future without intellectual property disputes.

## How to Contribute

1.  **Fork the repository:** Click the "Fork" button in the upper right of the GitHub interface.
2.  **Create a branch:** `git checkout -b feature/your-feature-name`
3.  **Make your changes:** Ensure that all tests pass (`pytest tests/` and `bin/opa test policies/ -v`).
4.  **Commit your changes:** `git commit -m "feat: Describe your feature"`
5.  **Push to your fork:** `git push origin feature/your-feature-name`
6.  **Submit a Pull Request:** Go to the original repository and click "Compare & pull request".

## Code of Conduct

Please treat all maintainers and contributors with respect.
